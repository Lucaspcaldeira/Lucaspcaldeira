### 📖 [psp-reader](https://github.com/Lucaspcaldeira/psp-reader)

> Leitor de **EPUB, PDF e TXT** para PlayStation Portable, escrito em C.

Uma página A4 reduzida para a tela de 480x272 deixa o texto com 4 pixels. Em vez
de encolher a página, o leitor reconstrói os parágrafos e repagina — como um
Kindle.

- Parser de PDF, leitor de EPUB e motor de reflow **escritos do zero**
- 497 asserções com AddressSanitizer e UndefinedBehaviorSanitizer
- CI no GitHub Actions · testado em PSP real

`C` `PSPSDK` `FreeType` `zlib`
